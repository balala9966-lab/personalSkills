# 视觉品味守则（anti-slop · 适配 bespoke 视频）

> 移植自开源 `taste-skill`（Anti-Slop Frontend），**只保留框架无关的"设计意图"规则**，全部对齐 study-dark 的 `design/theme.ts`（`C/F/S`）。
> 网页那套（响应式断点 / 滚动劫持 / Hero·Nav·Footer 结构 / Core Web Vitals / picsum 配图）与我们**时间轴驱动、固定 1920×1080、离线渲染**的形态无关，已剔除。
>
> 用法：子代理现写场景时当硬约束读；和已有铁律（beat 锚定、三分区、组件多样性、establishing 停留）**互补不重叠**——本守则管"配色/排版/构图/动画动机/上屏文案"这层"看着是否高级、是否一眼 AI 味"。

---

## A. 反默认 / 反 slop（最高优先 · 治"一眼 AI 味"）

LLM 出图有一组默认动作，全片只要踩到就掉档。**这些默认值一律不要,除非 KB/大纲明确要求**:

- **禁** AI 紫渐变、彩虹渐变文字、霓虹外发光（glow）、把毛玻璃糊到一切。study-dark 的高级感来自**克制的暗色 + 单一暖橙强调**,不要另起炉灶加大面积高饱和渐变背景。
- **禁** 无信息含义的装饰:纯装饰网格线 / 十字准星 / 旋转 90° 竖排文字 / 角标编号（`01 / 4`、`SECTION 02`、`Phase 03`）/ 地点时间天气条。装饰必须服务内容,否则删。
- **禁** 三等分等大卡片排排站、万物居中。见 D / E。
- study-dark 已定基调:动手前先问"这个视觉默认值是不是 LLM 惯性?"——是就换。

## B. 颜色纪律（对齐 `C` token）

- **全片一个强调色锁定 = 暖橙 `C.accent`**。冷蓝 `C.cool` / 绿 `C.good` **只承担语义角色**(对比项、正向结果/命中),不当"第二装饰强调色"到处撒。
- **同一语义全片同色**:某类对象第一次用蓝表示,后面别突然变绿。`C.layerHues` 只服务分层泳道(`LearningRoadmap`/`LayerStack`),**别外溢**到普通场景当花色用。
- 不用纯黑纯白(study-dark 本就是 `#1A1A1F` / `#F1F5F9`,守 token 即可);**阴影染底色用 `C.shadow`**,不要纯黑投影。
- 饱和度克制:辅助色调到能和炭灰底融洽,不要刺眼荧光。

## C. 排版层级（对齐 `F` / `S` token）

- **用字重 + 颜色 + 间距建层级,不是一味堆大字号**。标题按内容层级从 `S.display/h1/h2/h3` 选档——不是每个标题都顶 `S.display`。
- **正文行宽受限**:一行约 30–42 个全角字(或 60–70 拉丁字符),别让长句拉满 1920 宽一行到底——长了就换行或拆句。
- **强调词用同字体的字重/颜色**(加粗或 `C.accent`),**不要**塞一个异族字体的词进标题去"制造对比"(混字体强调是业余 tell)。
- **只用 `S` 的字号档位**,别在场景里手写中间字号(33、44…)制造第四、第五级——层级越少越清楚。
- 屏幕标题/标签**克制 uppercase 小标签**(eyebrow):同类小标签不要段段都来一条,会变成模板节奏。

## D. 形状一致性（对齐 `S.radius`）

- **全片一套圆角刻度**:统一用 `S.radius` / `S.radiusLg`,别这个卡片 8 那个 24。
- **卡片只在需要表达"分组/层级/抬升"时用**;否则用分隔线 + 留白分组,别万物套卡片盒(与"主舞台单件"铁律一致)。

## E. 构图多样 + 反重复（补"版式"维度,不止基元种类）

> 已有"组件多样性检查"管**基元种类**;本条管**构图/版式**——同一批基元也能摆出单调的版式。

- **反居中惯性**:不是每段都"标题居中 + 主件居中"。按内容选——左文右图、左图右文、非对称留白、对角线引导视线、上下分带。**但仍守三分区铁律**(标题带/主舞台/字幕带不互侵)。
- **同一构图家族整片别超过 2 段连用**:连着三段都是"居中标题 + 下方一排图标"就是版式单调,换构图。
- 留白是设计,不是空白:主舞台敢留大块负空间,别把元素铺满。

## F. 动画必须被动机驱动（移植价值最大 · 治"为炫而动"）

> 已有 beat 锚定铁律管**"何时动"**(对齐旁白);本条管**"该不该动 / 为何动"**。

- **每个入场/强调动画都要能一句话说清动机**,且只有这四类合法:①建立层级(把注意力引到该看的地方)②推进叙事(逐步揭示,序列对应讲解顺序)③反馈(回应某个动作)④状态变化(显示某物变了)。**说不清动机就删,让它静止**。
- **禁为炫而动**:无意义的持续漂浮 / 呼吸脉冲 / 旋转、"每个元素都飘进来"——这是 slop。study-dark 的高级感来自动得少而准。
- **缓动用 spring 物理**(Remotion `spring()`)或贴近 study-dark 的 ease 曲线,**不要线性匀速**位移(机械感、廉价)。
- 信息性的、不需要动的内容就让它静止(已显示的架构图不要一直微动)。

## G. 屏幕文案纪律（约束"画面上额外打的字")

> 字幕/配音真源是 `NARRATION`(单一真源,别在这里改);本条约束**画面上额外打的标题、标签、金句卡、角标**。

- **破折号 `—` / `–` 不上屏**:标题、标签、金句卡、角标一律不用,改普通连字符 `-` 或重组句子。这是 LLM 的头号视觉 tell。
- **不堆 AI 腔填充词**:"赋能 / 无缝 / 重塑 / 下一代 / 革命性 / 探索…的奥秘"——上屏文字用具体的动词 + 名词。
- **假精度数字要有据**:`99.99%`、齐整的 `50%`、编造的 `4.1×` 除非来自 KB 真实数据,否则不要为"显得专业"编。
- **标签即内容**:别用"步骤1 / 阶段2 / Phase 03 / Pass One"当标签,直接写它是什么("归一化""加权求和""缩放点积")。

## H. 留白与停留（指针 · 不重复造)

establishing 镜头的"看得清/不一闪而过"和尾部死留白,由已有铁律管:

- **太短一闪而过** → `holdEnd()` 借时间(PRIMITIVES.md 时序铁律第 5 条 + SKILL Step 1.5 / Step 5)。
- **太长死留白** → 见 video-eval 的 `pacing` 维度。
  本守则不重复,只提醒:克制的留白是高级感的一部分(B/D/E),但不等于"讲完后尾部静音过长"。

## 现写场景时的品味自检(并入 Step 2 子代理自检 · 纯代码级即可查)

- [ ] **A** 没踩 AI 默认值:无 AI 紫/彩虹渐变文字/霓虹发光/无信息装饰线/角标编号/地点时间条
- [ ] **B** 强调色全片只用 `C.accent`;蓝/绿只做语义角色;同一语义同色;无纯黑投影(用 `C.shadow`)
- [ ] **C** 标题按层级选 `S` 档位(不全顶 display);正文行宽受限;强调用同字体字重/色;无手写中间字号
- [ ] **D** 圆角统一用 `S.radius/radiusLg`;卡片只在表达分组时用
- [ ] **E** 构图不是又一个"居中标题+居中主件";同构图家族没连用 >2 段
- [ ] **F** 每个动画动机能一句话说清;无为炫而动/全员飘入;缓动非线性
- [ ] **G** 屏幕额外文字:无破折号上屏、无 AI 腔填充词、无编造精度数字、标签即内容
