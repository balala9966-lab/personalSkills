# 脚本类型专属约束（详细）

按 `script_type` 应用对应的叙事结构和硬约束。

---

## 科普类（SCIENCE_CONSTRAINTS）

### 叙事结构（比例分配，按 suggested_duration 换算秒数）

| 区间      | 内容                      | 说明                                               |
| --------- | ------------------------- | -------------------------------------------------- |
| 0 ~ 6%    | 钩子                      | 抛出反直觉事实/数据/问题，不许任何背景铺垫         |
| 6% ~ 18%  | 问题锚定                  | 把事实跟观众生活关联，可简要交代历史由来（一句话） |
| 18% ~ 33% | L1 基础认知（是什么）     | 用具体类比建立直觉理解                             |
| 33% ~ 55% | **L2 原理深潜（为什么）** | 最长段。三层递进：机构层 → 物理层 → 设计层         |
| 55% ~ 70% | L3 应用图景（用在哪儿）   | 覆盖 2-3 个典型领域 + 工程权衡一句话               |
| 70% ~ 80% | L4 旁证互联               | 1-2 条关联知识，形成跨领域认知网络                 |
| 80% ~ 88% | 高潮                      | 一个让人记住的画面/数据/结论（最好呼应钩子）       |
| 88% ~ 95% | 收尾延伸                  | 留一个开放问题                                     |
| ~5%       | 段间停顿                  | 呼吸节奏                                           |

### 核心技法

1. **类比驱动**：每个抽象概念必须配一个日常类比（不是"像工厂"，是"像 37 万亿个工人施工的建筑工地"）
2. **悬念式提问**：在回答前先提问。L1→L2 过渡处必须设计一个"为什么"的悬念
3. **可视化思维**：所有描述都应该"可以在视频中拍出来"
4. **每 30 秒一个小恍然大悟**：L2 原理段至少提供 2-3 个顿悟时刻
5. **L2 核心地位**：不只要说"X 更好"，更要说明白"为什么更好"的物理本质

### 好开场示范

✅ 「你的免疫系统刚刚消灭了一个癌细胞。就在你听这句话的时候。」 — 反直觉+即时感
❌ 「免疫系统是人体重要的防御系统。」 — 教科书式+零吸引力

## 学习/教程类（TUTORIAL_CONSTRAINTS）

### 根本区别

科普视频让观众"了解、惊叹、记住"；学习视频让学习者**理解、能动手、能解释**。

- ❌ 没有可运行代码 = 不是学习视频
- ❌ 没有实战自检场景 = 不是学习视频
- ❌ 没有学习目标清单 = 不是学习视频
- ❌ 没有系列定位 + 当天意义 = 不是系列学习视频
- ❌ 没有承上启下的核心回顾 + 下一篇引入 = 不是系列学习视频
- ❌ 不许用"面试题"措辞——必须用"实战自检"/"真实场景"/"工程场景"
- ❌ 用欢迎词开场、钩子不前置 = 开头跳出率高，不合格
- ❌ 没有中段钩子 + 金句 + 结尾互动 = 完播和传播都弱，不合格

### 系列学习视频的开头结构（强制·钩子前置，降跳出率）

**核心原则：前 3 秒决定生死，钩子=点题合一，框架瘦身、30 秒进正题。** 开头依次包含（**总段数 ≤2-3、占比 ≤10%**）：

1. **钩子＝点题（前置·合一）**（0-5%）— 前 3 秒直接抛痛点/悬念，**首句必须是问题或反常识陈述，且把本集主题词当成"答案"点出**，一句话既抓人又点题，不许任何欢迎词/背景铺垫
   - ✅「为什么大模型能听懂你的话？秘密藏在这个叫"注意力"的机制里。」← 抓人＋点出主题"注意力"
   - ✅「同一句话，AI 一秒读完；换成 RNN 得一个字一个字啃。差距从哪来？答案就是今天的『Transformer 架构』。」
   - ❌「欢迎来到 LLM 工程师路线图 Day 2。」— 欢迎词＋报编号，**严禁**
   - ❌ 钩子抛完痛点却没点出主题词 → 等于没点题，返工
   - 紧跟可加**半句系列衔接**（用主题、不报 Day 号）：「接着上一集的注意力，这一集把整个 Transformer 拼起来。」
   - `visual_anchor` 必须强视觉冲击：核心概念特写 / 动态特效，禁止静态公式

2. **核心问题（总）— 并进钩子段，不独立**（钩子第二句）— 把刚点的主题展开成"全片要回答的那一个问题"，作为"总-分-总"里的**总**，结尾回顾必须呼应它。**不单开一段**
   - ✅（接钩子）「说白了就一个问题：一个词，怎么知道该'看'句子里的哪些其他词？」

3. **今天的意义与价值（瘦身·只留最狠一句）**（约 5-10%）— **只讲最戳的一件事**（学不会会被卡在哪 / 学会解锁什么，挑一个），其余别在开头堆，拆散编织进正文对应模块或结尾意义段
   - ✅「理解不了注意力，后面 SFT、RLHF、RAG 全是空中楼阁。」← 一句话，戳"学不会的后果"
   - ❌ 开头连讲"为什么核心＋学不会后果＋解锁什么"三件事 → 枯燥、占比超标，返工
   - 此句可顺带埋**金句**（口诀/比喻）；路线路标作本段 coda 末句、不单开一段

### 主体结构（20-85%·总-分）

| 区间      | 内容                                                                                                                                                  |
| --------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| 20% ~ 26% | 学习目标预告（3-5 条具体能力）                                                                                                                        |
| 26% ~ 40% | L1 基础认知                                                                                                                                           |
| 40% ~ 54% | **实战演示**（3-5 行核心代码 + 打字机加速生成，narration 念"做什么"不念代码字符）                                                                     |
| 54% ~ 57% | **中段内容钩子（新·强制）**：提问/悬念再次抓注意力并引导互动，如「你觉得注意力机制最难理解的是哪部分？」。写入 `interaction_prompts`（type=中段钩子） |
| 57% ~ 72% | L2 原理深潜                                                                                                                                           |
| 72% ~ 85% | L3 应用拓展                                                                                                                                           |

### 系列学习视频的结尾结构（强制·总-分-总收口 + 互动）

| 区间       | 内容                | 要求                                                                                                                             |
| ---------- | ------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| 85% ~ 90%  | 核心关键点回顾+金句 | 思维导图式，不是详细复述。3-5 个核心要点 bullet 闪回，**呼应开头的"核心问题（总）"**，落 ≥1 金句                                 |
| 90% ~ 93%  | 下一篇引入问题      | **不许哲学问题**。必须是下一篇明确会回答的实操问题                                                                               |
| 93% ~ 96%  | 下一篇明确预告      | 一句话点题下一篇题目和能学到的能力。不许"下回分解"                                                                               |
| 96% ~ 100% | 互动引导 + 关注系列 | **发起话题讨论**（如「你还想了解大模型的哪些底层原理？评论区告诉我」，写入 `interaction_prompts` type=结尾话题）+ 一句话关注呼吁 |

### 强制内容清单（缺任一即 fail）

1. **钩子＝点题段**: 第一段必须是钩子，前 3 秒抛核心冲突/悬念，首句是问题或反常识、**且点出本集主题词**，visual_anchor 强视觉冲击（特写/动态特效）。**严禁欢迎词开场、严禁念 Day 号**
2. **核心问题（总）**: 把主题展开成全片要回答的那一个问题，**并进钩子段（钩子第二句）、不单独成段**，结尾回顾呼应它
3. **代码段**: 3-5 行核心可运行代码（不超过 8 行），visual_anchor 标"打字机加速 (charsPerSec≈30)"，完整代码放 `demo_code` 字段
4. **中段内容钩子**: ≥1 个提问/悬念，写入 `interaction_prompts`（type=中段钩子）
5. **金句**: ≥1 条易记口诀/比喻，写入 `key_quotes`，编织进价值段与回顾段
6. **实战自检场景段**: 至少 3 个真实工程场景，每个含「问题→答案→优化方法→常见踩坑」四件套
7. **学习目标段**: 开头列 3-5 条「今天看完能...」，结尾用「你现在应该能...」重复一遍
8. **系列衔接**: 钩子后用半句、以主题承接（上集主题→本集主题），**不报 Day 号/编号**；并进钩子段或意义段，不单独成段
9. **意义与价值**: 开头只留最狠一句（卡点或解锁挑一个），其余拆散编织进正文/结尾，不在开头堆三件事
10. **核心回顾段**: 思维导图式
11. **下一篇预告段**: 明确题目
12. **互动引导段**: 发起话题讨论，写入 `interaction_prompts`（type=结尾话题）+ "关注系列"呼吁
13. **可实践锚点**: 每个抽象概念旁配"动手验证"具体方式

### 开局炫技铁律（seq0·留人生死线·硬性·绝对要求·rubric `opening_viz_richness`）

**绝对禁止简单、无吸引力的内容放在开头。** 开局可视化必须同时满足四项（缺一不合格、踩红线打回重做）：

1. **钩子**：前 2 秒就抓人——首句断言式冲击 + 点出本集主题词（禁反问套话/欢迎/CTA/回顾/大纲预告）。
2. **具体示例**：用一个**真实、有分量（最好复杂、有规模）的示例**驱动开局，不是抽象概念。措辞要讨好、专业——**说"复杂的任务/真实项目"，别用"大活"这类俗气说法**。
3. **可视化贴切**：画面就是这个示例**在发生**（看着它跑/搭/变/算），关掉声音也看得懂这一段。
4. **可视化炫技**：信息丰富、有运动、有尺度感、产品级精致——多元素协同 / 大计数器狂飙 / 流式日志 / 图表动效 / 辉光强调；前段用 ease-out 提速让"效果立刻可见"。配得上 study-dark 高级感。

**红线（命中=critical·一律打回）**：开局前几帧是 ❌静止画面 / ❌小字矩阵 / ❌单调清单缓慢填色 / ❌纯抽象曲线或柱图 / ❌一张静态卡 / ❌"标题+一句话+静态示意图"。自检：把 seq0 前 2 秒缩到手机尺寸，"会不会立刻划走"——会就是不合格。
**正例（A12 定稿·可参照）**：「看着一个 AI 把一个复杂全栈应用飞速盖起来」——运营后台 dashboard（导航+KPI卡+柱状图+数据表）一块块搭出来 + 右侧大计数器狂飙(✅功能 0→200 / ⏱运行 0→6h / 🔀commit) + 流式构建日志终端(文件一行行刷出) + harness 循环驱动 → ✓交付完成。**反例（连否两版）**：抽象准确率断崖曲线、默认全红的小格子清单缓慢填绿。

### 开场禁忌

- ❌ 用"欢迎来到 / 这是第 N 天 / 今天我们来聊聊 / 大家好"等欢迎词开场
- ❌ 旁白里念"Day 几 / 第 N 集 / 第 N 天"等集序数字（系列衔接只用主题名）
- ❌ 钩子抛完痛点却没点出本集主题词（钩子＝点题，必须二合一）
- ❌ 把系列定位放在第一段（必须钩子在前）、或让核心问题/意义各自独立成段（要合并、瘦身）
- ❌ 开场第一句不是问题/反差/反常识
- ❌ 开场 visual_anchor 是静态公式/纯文字（必须强视觉冲击）
- ❌ **开局可视化简单、无吸引力（静止/小字矩阵/单调清单/抽象曲线/静态卡）= critical**（见上「开局炫技铁律」）
- ❌ **示例措辞俗气（如"大活"）**——用"复杂的任务/真实项目"等专业讨好说法

### 收尾禁忌

- ❌ 哲学开放问题
- ❌ 抒情升华
- ❌ "下回分解"式无内容预告
- ❌ "面试题"措辞
- ❌ 结尾没有互动话题引导
- ❌ 没有关注引导的结尾

### 视觉风格建议（写进对应段的 visual_anchor，给下游 scene-design 定调）

- **钩子前置段**：核心概念特写 / 动态特效，3 秒内冲击力拉满（如词向量空间里一个词被周围词"点亮拉扯"的特写），禁止静态公式
- **系列衔接**：路线图卡片可视化（时间轴 + 当前位置高亮 + 后续节点预览，**卡片上可标主题名，旁白不念编号**），半句快速带过
- **实战代码段**：terminal 黑底等宽字体，打字机加速 (charsPerSec≈30)，代码区占屏 1/2，另一半同步运算可视化
- **中段钩子段**：大字提问悬浮 + 留白停顿，制造"等一下，这里有问题"的注意力回收
- **核心回顾段**：5 个要点用思维导图气泡同时浮现，金句用大字定格
- **互动引导段**：极简画面 + 大字话题（"评论区聊聊：你还想懂哪个底层原理？"）+ "关注系列，下集讲〈主题名〉"（**用主题名预告，不报 Day 号**）

## 故事类（STORY_CONSTRAINTS）

### 三幕式结构

- **第一幕 (25%)**: 建立 — 角色、世界、核心冲突的种子
- **第二幕 (50%)**: 对抗 — 冲突升级、角色成长、转折点
- **第三幕 (25%)**: 解决 — 高潮、情感释放、余韵

### 核心技法

1. **展示而非告知 (Show Don't Tell)**：不直接说"他很悲伤"，而是描述"他攥着那张照片，指节发白"
2. **角色弧光**：主角在故事前后必须有明确改变
3. **冲突驱动**：每个场景必须有冲突（外部或内心）
4. **感官细节**：每个场景至少一个感官描述

### 情绪曲线

起 → 升 → 跌 → 急升 → 缓降

## 漫剧类（COMIC_CONSTRAINTS）

### 叙事结构

快节奏场景切换，每个场景 8-15 秒：

- 场景之间用视觉反差连接（大喜接大悲，大动接大静）
- 对话驱动叙事，旁白极少使用
- 每个场景至少一个"视觉梗"

### 核心技法

1. **视觉优先**：先想画面再写台词
2. **强对比**：连续场景间制造视觉或情绪反差
3. **夸张表现**：漫画式夸张（瞪眼、汗滴、黑影、速度线）
4. **节奏紧凑**：不交代背景，直接进入冲突/笑点

### 对话要求

- 每句话不超过 15 字
- 一问一答的抛接节奏
- 避免解释性对话

## 开源速递类（OSS_DIGEST_CONSTRAINTS）

每周 GitHub AI 热门增长项目的技术速览。定位是**干货密度优先**：讲清这项目解决什么问题、核心架构、技术亮点。**弱钩子、弱引导**——不需要科普/学习类那套留人三件套（情绪钩子、中段钩子、结尾互动、金句、关注引导），观众是来看技术干货的，直接讲。

### 根本区别

- 科普让观众"惊叹、记住"，学习让人"能动手"，开源速递让人**快速看懂一个项目的技术内核与亮点**
- ❌ 没讲清"解决什么问题" = 不合格（观众不知道这项目为何存在）
- ❌ 没有核心架构的可视化呈现 = 不合格（架构图是本类型的视觉主轴）
- ❌ 只罗列功能、不说"为什么这么设计/好在哪" = 流水账，不合格
- ✅ 不需要强情绪钩子/中段钩子/结尾互动/金句/关注引导——有就删，别硬塞

### 叙事结构（3-5 min，比例分配）

| 区间       | 内容             | 说明                                                                            |
| ---------- | ---------------- | ------------------------------------------------------------------------------- |
| 0 ~ 8%     | 切入             | 一句话直说：这项目是什么 / 解决什么痛点。**不情绪铺垫、不悬念钩子**，直接抛事实 |
| 8% ~ 33%   | 架构总览         | **核心架构一张图**——本片视觉主轴；讲清主要模块与数据流向                        |
| 33% ~ 78%  | 技术亮点（最长） | 2-3 个亮点/创新点逐个拆，每个配一句"为什么这么设计 / 好在哪 / 比同类强在哪"     |
| 78% ~ 93%  | 典型用法/效果    | 一个真实用法或效果对比，落地这项目能干什么（有数据/对比更佳）                   |
| 93% ~ 100% | 收束             | 它适合谁 / 边界在哪，一句带过                                                   |

### 核心技法

1. **架构图驱动**：架构总览段必须给一张"可拍"的核心架构图（模块 + 数据流），后续亮点段都挂在这张图上展开
2. **亮点要讲因果**：每个技术亮点不能只说"它支持 X"，要说清"为什么这么设计、解决了什么、代价是什么"
3. **对比定位**：尽量给"它出现前大家怎么办" / "和同类比强在哪"的一句对比，帮观众建立坐标
4. **可视化思维**：所有描述"可以在视频里拍出来"（沿用全局硬约束）

### 保留的全局硬约束

- **概念两段式解释**：出现新术语/缩写仍要"先专业后通俗"立刻讲清，别假设观众都懂
- **visual_anchor 可拍、动画化**
- **具体性**：禁模糊词，用具体数字/事实（star 数、性能数据、token 节省比例等）
- **禁废话开场**

### 不强制（与科普/学习类的区别）

- 情绪曲线冲到 5、每 30 秒恍然大悟、高潮呼应钩子 —— 不要
- 留人三件套（开头情绪钩子前置 / 中段钩子 / 结尾互动引导 / 金句 / 关注引导）—— 不要
- 系列定位段 —— 走自由主题，无 series_context，不写
- `key_quotes` / `interaction_prompts` —— 本类型**非必填**

### 开场示范

✅ 「codegraph 把你的代码库预先建成知识图谱，让 Claude Code、Cursor 这类 AI 编程助手少调几次工具、少烧 token。」 — 一句话说清是什么+解决什么
❌ 「你有没有想过，AI 编程助手为什么有时候那么慢？」 — 这是科普钩子，本类型不需要

## 信息速递类（INFO_DIGEST_CONSTRAINTS）

定期把**某领域一段时间内发生了什么 + 为什么 + 怎么看**讲清楚的速递。首个实例是**股市信息速递**（每周 A股/港股复盘），框架可复用到任何"数据驱动的领域速递"。定位与开源速递同属**信息类传播**（弱钩子、干货密度优先、不要留人三件套），但区别关键：

- 开源速递讲「**一个项目的技术内核**」，信息速递讲「**一段时间内某领域的变化、归因与研判**」——**核心交付是分析质量**：每个判断要有数据锚、推理链、证伪信号，不是贴标签、喊口号。
- ❌ 只陈述现象不归因（"今天跌了" 不说为什么跌）= 不合格
- ❌ 判断只贴标签、无数据锚（"涨太多了，资金获利了结"）= 空话，不合格
- ❌ 单点预测后市（"下周必反弹"）= 不合格，只能给**多空双情景 + 观察变量**
- ✅ 不需要强情绪钩子/中段钩子/结尾互动/金句/关注引导——有就删

### 根本区别（与开源速递）

开源速递是"看懂一个项目"，信息速递是"看懂一段行情/一组数据背后发生了什么"。**它的视觉主轴不是架构图，而是数据**（指数卡/分化榜/排序归因/多空情景）；**它的灵魂不是亮点罗列，而是反空话的分析链**。

### 反空话五步链（核心铁律·每个核心判断必走，不许只给结论）

```
数据锚点 → 对比/参照 → 推理链 → 反向限定(证伪信号) → 定性结论
```

- ❌ 贴标签：「涨太多，PE 194 倍、99% 分位，资金落袋为安。」（只有数据+结论，跳过了推理与证伪）
- ✅ 五步链：「194 倍——是英伟达的 4 倍、2021 周期顶的 2.4 倍，99% 历史分位，安全垫极薄（数据锚+对比+推理）。但贵不等于会崩——看资金去向：从半导体切向煤炭/机器人，是高低切换不是夺路出逃（反向限定/证伪信号）。所以这轮杀的是估值、不是逻辑（定性结论）。」
- **次要点简略带过**（详略节奏，别每点都摊开走五步链——核心判断细讲，背景/枝节一句话）。

### 删万能空话（具体可证伪，否则删）

- 禁词：「支撑仍在」「值得关注」「趋势向好」「前景广阔」「不确定性加大」「保持谨慎乐观」——这类话**正反都成立、无法证伪**，一律换成具体可证伪的东西（哪个数、对比谁、什么条件下成立），换不出来就删。
- ✅「南向 6 月转净流入」（可查、可证伪） ❌「资金面有支撑」（万能空话）

### 多空并陈（核心判断给反方一句）

任何方向性研判，必须紧跟一句反方/证伪条件。展望段一律给**偏谨慎 / 偏乐观双情景**，每个情景写明"在什么条件下成立"（if-then），不押单边。

### 事实 / 观点分离（口播措辞 + 屏上角标双重区分）

- **口播**：陈述事实用「**数据显示 / 交易所披露 / 收在…**」；给判断用「**我们倾向认为 / 这更像是 / 观点而非预测**」。两者措辞必须可区分。
- **屏上**：每屏标【**数据**】或【**研判**】角标（scene-design 落地），观众一眼分清哪是客观数、哪是主观判断。

### 数据纪律（接口可复跑 + 拿不到不编 + 降级标缺）

- 能接口化复跑的核心数字（指数/个股涨跌幅）→ 标【数据】实锚，留痕到 `data_verified.json`。
- 只有搜索值的（估值分位/资金面/成交量/板块）→ **标来源**（"据公开数据"），或诚实降级为定性，**不编精确数字**。
- 已停披露的（如北向资金实时）→ 用替代口径（南向+两融+成交量）并**明确标缺**。
- 走势研判一律标"**观点、不构成投资建议**"，结尾免责段必备。

### 六层分析骨架（叙事框架·每层先事实后归因再观点）

| 层 | 内容 | 要点 |
| -- | ---- | ---- |
| L1 行情面 | 指数 + 个股分化 | 涨跌幅实锚；点出"普涨/普跌还是结构分化" |
| L2 资金面 | 南北向 / 两融 / 龙虎榜 / 成交量 | 北向已停实时披露 → 南向+两融+量替代，标缺 |
| L3 估值面 | 分位 / PE / 安全垫 | 走五步链；贵≠会崩，看资金去向证伪 |
| L4 情绪面 | 风险偏好 / 高低切换 | 区分"出逃"还是"切换" |
| L5 消息面 | 触发器 vs 主因 | 过滤噪音；分清"下周风险"和"本周原因"的时间差 |
| L6 宏观地缘 | 尾部风险 | 只放大波动、不量化预测 |

**溯源 = 排序归因**（主因 / 次因 / 放大器，按重要性排序，不平铺）；**展望 = 多空双情景 + 观察变量(if-then)**，不做单点预测。

### 叙事结构（2-4 min，比例分配；股市实例）

| 区间 | 内容 | 说明 |
| ---- | ---- | ---- |
| 0 ~ 8% | 开场点题 | 一句话说清"本期发生了什么 + 核心看点"，不情绪铺垫、不悬念钩子（如"温和回调，但平静之下是结构分化"） |
| 8% ~ 28% | 行情速览（L1） | 指数卡实锚涨跌；快节奏数据轮转 |
| 28% ~ 43% | 结构看点 / 个股分化 | 点出"冰火两重天"，谁领跌谁逆势（实锚个股） |
| 43% ~ 68% | 排序归因（最长） | 主因/次因/放大器逐条走五步链；核心判断细讲、次要带过 |
| 68% ~ 88% | 展望·多空情景 | 偏谨慎/偏乐观双情景 + if-then 触发条件 |
| 88% ~ 95% | 观察变量 | 4 个左右可跟踪变量（if-then 监控清单） |
| 95% ~ 100% | 免责 | 数据来源 + 走势仅为观点、不构成投资建议 |

### 保留的全局硬约束

- **概念两段式解释**：新术语（如"分位""高低切换""费半"）首次出现先专业后通俗立刻讲清。
- **visual_anchor 可拍、数据驱动**：每段标核心画面（指数卡/分化榜/归因排序/情景卡）。
- **具体性**：禁模糊词，用具体数字 + 来源。
- **禁废话开场**。

### 不强制（与科普/学习类的区别）

- 留人三件套（情绪钩子前置 / 中段钩子 / 结尾互动 / 金句 / 关注引导）—— 不要
- 系列定位段 / `series_context` —— 走自由期次（如 2026-06-W1），不写 series_context
- `key_quotes` / `interaction_prompts` —— 本类型**非必填**

### 开场示范

✅ 「本周 A股与港股温和回调，但平静之下，是一场明显的结构分化。」 — 一句话点出"发生了什么 + 核心看点"，直接进数据
❌ 「最近股市又跌了，很多投资者都很关心后市怎么走。」 — 模糊词 + 空话铺垫，无信息
